# VoxaChat

Local chat agent UI with filesystem tools (TEV/JEV) and a themed shell.
Extracted from Voxa — **chat only** (no TTS, music, or voice training).

## Quick start

```powershell
pip install -r requirements.txt
# Ensure Ollama is running
python bin/server.py
# → http://127.0.0.1:8766
```

Windows helper: `bin/start-windows.ps1`  
Unix helper: `bin/start.sh`

Click **+** next to Workspace to choose a folder via the native directory picker.
